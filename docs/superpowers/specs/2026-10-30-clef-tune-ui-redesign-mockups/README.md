# UI redesign mockups

These are the screens agreed with the user on 2026-10-30, for
`../2026-10-30-clef-tune-ui-redesign-design.md`. They are throwaway HTML fragments made for review.
They set the look, spacing and motion. They are not code to reuse as-is.

They were shown inside a review frame, so the controls above each mockup look plainer when a file
is opened on its own. Light/dark buttons and option switches sit above each mockup.

| File | Screen |
|---|---|
| `01-style.html` | The chosen style: C's elements, B's colours, A's motion |
| `02-welcome.html` | Welcome: first visit and coming back |
| `03-your-data.html` | Step 1: empty, uploaded (desktop and phone), roles, checks |
| `04-what-to-predict.html` | Step 2: question list and editor, "Asked as" tip |
| `05-settings.html` | Step 3: chosen layout C (phone and desktop), next to B on a phone |
| `05b-settings-a-b.html` | Step 3 layouts A and B, kept to revisit |
| `06-train.html` | Step 4: ready, running (simulated), Your models |
| `07-results.html` | Results: headline dots, per-question lines, details |
| `07b-row-noun-and-templates.html` | The row noun and mistake templates across three files |
| `08-predict.html` | Predict a new spreadsheet: choose, running, ready |

Where the design document's wording differs from a mockup, the document wins. For example,
`07-results.html` predates the "expected output" wording.
